## 8.1. Introduction to AHP-TOPSIS Algorithm

The matchmaking system in the MangKos application has moved away from static weighting to the integration of two powerful Multi-Criteria Decision Making (MCDM) algorithms:

1. **Analytic Hierarchy Process (AHP)**: Developed by Thomas L. Saaty (1980), used to determine priority weights of criteria subjectively through pairwise comparisons. This allows the MangKos system to understand that for User A, "Cleanliness" might be far more important than "Budget", while for User B the opposite applies.

2. **Technique for Order of Preference by Similarity to Ideal Solution (TOPSIS)**: Used to rank roommate candidates. The main principle is selecting candidates with the shortest distance from the positive ideal solution (perfect candidate) and the farthest distance from the negative ideal solution (least suitable candidate).

**Why AHP-TOPSIS?** This combination is highly ideal for matchmaking because AHP handles the psychological side of user preferences that are often inconsistent, while TOPSIS provides efficient mathematical calculations to process thousands of candidates in real-time.

## 8.3. Phase 1: Analytic Hierarchy Process (AHP)

### A. Pairwise Comparison Matrix

Users are asked to compare the importance of one criterion against another using the Saaty Scale (1-9):
- 1: Equally important
- 3: Slightly more important
- 5: More important
- 7: Much more important
- 9: Absolutely more important

**Example Pairwise Matrix (User Input):**
If a user fills out the questionnaire, the system will build a 7×7 matrix A:

|  | C1 | C2 | C3 | C4 | C5 | C6 | C7 |
|:---|:---|:---|:---|:---|:---|:---|:---|
| **C1** | 1 | 2 | 3 | 5 | 5 | 7 | 9 |
| **C2** | 0.5 | 1 | 2 | 3 | 3 | 5 | 7 |
| **C3** | 0.33 | 0.5 | 1 | 2 | 2 | 3 | 5 |
| **C4** | 0.2 | 0.33 | 0.5 | 1 | 1 | 2 | 3 |
| **C5** | 0.2 | 0.33 | 0.5 | 1 | 1 | 2 | 3 |
| **C6** | 0.14 | 0.2 | 0.33 | 0.5 | 0.5 | 1 | 2 |
| **C7** | 0.11 | 0.14 | 0.2 | 0.33 | 0.33 | 0.5 | 1 |

### B. Weight Calculation (Priority Vector)

The system normalizes the matrix through these steps:
1. Calculate the sum per column
2. Divide each element by its column sum
3. Calculate the row average (Geometric Mean) to obtain weights ($w_j$)

**Example Output Weights ($w_j$):**
$$w = [0.364, 0.222, 0.148, 0.088, 0.088, 0.054, 0.036]$$

### C. Consistency Check (CR)

To ensure valid user input (not random clicks), the system calculates the Consistency Ratio (CR):

1. Calculate $\lambda_{max}$ (Principal Eigenvalue)
2. Calculate $CI = \frac{\lambda_{max} - n}{n - 1}$ (where $n = 7$)
3. Calculate $CR = \frac{CI}{RI}$ (RI for $n = 7$ is 1.32)

**Condition:**
- If $CR \leq 0.1$, weights are accepted and proceed to TOPSIS
- If $CR > 0.1$, the system rejects input and asks the user to repeat the questionnaire due to answer inconsistency

## 8.4. Phase 2: TOPSIS (Ranking Candidates)

After obtaining weights from AHP, the system will rank 8 roommate candidates.

### Step 1: Decision Matrix (X)

Candidate performance matrix based on their profile questionnaires:

| Candidate | C1 | C2 | C3 | C4 | C5 | C6 | C7 |
|:----------|:---|:---|:---|:---|:---|:---|:---|
| Budi | 5 | 0 | 5 | 4 | 2 | 3 | 4 |
| Chandra | 4 | 1 | 4 | 5 | 3 | 2 | 5 |
| Dimas | 3 | 0 | 3 | 2 | 5 | 5 | 2 |
| ... (up to 8) | | | | | | | |

### Step 2: Vector Normalization (R)

Normalize matrix elements using the formula:
$$r_{ij} = \frac{x_{ij}}{\sqrt{\sum_{i=1}^{m} x_{ij}^2}}$$

### Step 3: Weighted Normalized Matrix (V)

Multiply the normalized matrix with AHP weights:
$$v_{ij} = w_j \times r_{ij}$$

### Step 4: Determine Ideal Solutions

- **Positive Ideal Solution (PIS - $A^+$)**: Best values (max for benefit, min for cost)
- **Negative Ideal Solution (NIS - $A^-$)**: Worst values

### Step 5: Calculate Distance ($S^+$ and $S^-$)

Calculate Euclidean distance of each candidate to ideal solutions:
$$S_i^+ = \sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^+)^2}$$
$$S_i^- = \sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^-)^2}$$

### Step 6: Closeness Coefficient (CC)

Calculate final compatibility score:
$$CC_i = \frac{S_i^-}{S_i^+ + S_i^-}$$

The value ranges from 0 to 1. Values approaching 1 indicate highly suitable candidates.

## 8.6. Summary Formulas & Pseudo-code

### Standard Notation (LaTeX)

$$w_j = \frac{1}{n} \sum_{k=1}^{n} \frac{a_{jk}}{\sum_{i=1}^{n} a_{ik}}$$

$$CC_i = \frac{\sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^-)^2}}{\sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^+)^2} + \sqrt{\sum_{j=1}^{n} (v_{ij} - v_j^-)^2}}$$

### Backend Implementation Pseudo-code

```python
# Phase 1: AHP Weight Calculation
def calculate_ahp_weights(pairwise_matrix):
    # Step 1: Normalize columns
    column_sums = sum(pairwise_matrix, axis=0)
    normalized_matrix = pairwise_matrix / column_sums
    
    # Step 2: Calculate priority vector (row averages)
    weights = mean(normalized_matrix, axis=1)
    
    # Step 3: Consistency Check
    lambda_max = max(eigenvalue(pairwise_matrix))
    CI = (lambda_max - n) / (n - 1)
    CR = CI / RI  # RI = 1.32 for n=7
    
    if CR > 0.1:
        raise ValueError("Inconsistent input, please re-fill questionnaire")
    
    return weights

# Phase 2: TOPSIS Ranking
def topsis_ranking(candidates_matrix, weights):
    # Step 1: Normalize decision matrix
    m, n = candidates_matrix.shape
    R = candidates_matrix / sqrt(sum(candidates_matrix^2, axis=0))
    
    # Step 2: Create weighted normalized matrix
    V = R * weights
    
    # Step 3: Determine ideal solutions
    A_positive = max(V, axis=0)  # For benefit criteria
    A_negative = min(V, axis=0)  # For cost criteria
    
    # Step 4: Calculate distances
    S_plus = sqrt(sum((V - A_positive)^2, axis=1))
    S_minus = sqrt(sum((V - A_negative)^2, axis=1))
    
    # Step 5: Calculate closeness coefficient
    CC = S_minus / (S_plus + S_minus)
    
    # Step 6: Rank candidates
    rankings = argsort(CC)[::-1]
    return rankings, CC
```

### Variable Definitions

| Variable        | Meaning                                         |
| --------------- | ----------------------------------------------- |
| $n$             | Number of criteria (7 in this case)             |
| $m$             | Number of candidates                            |
| $a_{jk}$        | Element in pairwise comparison matrix           |
| $w_j$           | Weight of criterion j                           |
| $\lambda_{max}$ | Principal eigenvalue                            |
| $CI$            | Consistency Index                               |
| $CR$            | Consistency Ratio                               |
| $RI$            | Random Index (1.32 for n=7)                     |
| $x_{ij}$        | Performance score of candidate i on criterion j |
| $r_{ij}$        | Normalized performance score                    |
| $v_{ij}$        | Weighted normalized score                       |
| $v_j^+$         | Positive ideal solution value for criterion j   |
| $v_j^-$         | Negative ideal solution value for criterion j   |
| $S_i^+$         | Distance to positive ideal solution             |
| $S_i^-$         | Distance to negative ideal solution             |
| $CC_i$          | Closeness coefficient (final match score)       |
